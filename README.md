# Area Arena

Area Arena is a competitive, first-person battle royale game designed for the Lagos Life platform.

## Project structure

- `index.html` — Main game entry point
- `css/style.css` — Game styling and UI layout
- `js/main.js` — Core game logic and loop
- `js/vatar-games-v1.js` — VATAR SDK integration
- `js/controls.js` — Touch input handling
- `assets/textures/` — Visual surfaces
- `assets/models/` — 3D assets
- `assets/audio/` — Sound effects and music

Open `index.html` in a browser to view the starter page.
